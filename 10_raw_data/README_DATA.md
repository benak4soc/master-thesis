# Raw CICEVSE2024 data

Large raw network CSVs are not stored here (GitHub 100MB limit).

Download the official dataset:
https://www.unb.ca/cic/datasets/evse-dataset-2024.html

Expected folders:
- `host_events/`
- `network_traffic_EVSE_A/` (charging/idle)
- `power_consumption/`

Then run scripts starting from `02_preprocessing/`.
